O que são dados harmónicos?

As previsões harmónicas usam constituintes (por exemplo M₂, S₂, K₁ e O₁), cada um com amplitude e fase, para estimar a altura da maré ao longo do tempo. A cobertura e a qualidade variam por local. Esta interface só mostrará constantes quando a API devolver dados válidos; não inventa constantes para locais sem estação/modelo.

Sem dados harmónicos disponíveis.

Para navegação, pesca ou segurança costeira, confirme sempre com o Instituto Hidrográfico e com avisos oficiais. A previsão de maré pode não estar disponível para todos os pontos da ilha.
